## 🎮 Об игре

**Ping Pong** — небольшая двухмерная аркадная игра в духе классического Pong. Два игрока управляют ракетками, отбивают мяч и стараются набрать больше очков.

Проект создан для практики разработки игр на Pygame и демонстрирует работу с игровым циклом, спрайтами, столкновениями, управлением, подсчётом очков и звуковыми эффектами.

## ✨ Возможности

- 👥 Локальная игра для двух игроков на одном компьютере
- 🏓 Управление ракетками с клавиатуры
- ⚡ Отскок мяча от стен и ракеток
- 📈 Увеличение скорости мяча после удара о ракетку
- 🧮 Подсчёт очков и победных раундов
- 🏆 Финальный экран победы
- 🔊 Фоновая музыка и звуковые эффекты
- 🎨 Пользовательские изображения, фон и игровые ресурсы

## 🕹️ Управление

| Игрок | Движение вверх | Движение вниз |
|:---:|:---:|:---:|
| 👈 Левый | `W` | `S` |
| 👉 Правый | `↑` | `↓` |

Чтобы завершить игру, закройте окно приложения.

## 🏁 Правила игры

1. Каждый игрок управляет своей ракеткой.
2. Необходимо отбивать мяч и не позволять ему покинуть свою сторону поля.
3. Когда мяч проходит за ракетку, соперник получает очко.
4. Игрок, первым набравший **5 очков**, выигрывает раунд.
5. Игра продолжается до **5 выигранных раундов**.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/slavangngng/ping_pong.git
cd ping_pong
```
### 2. Установка Pygame
Рекомендуется использовать виртуальное окружение:

```bash
python -m venv .venv
```

Активация виртуального окружения:

Windows:

```bash
.venv\Scripts\activate
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Установите зависимость:

```bash
pip install pygame
```

### 3. Запуск
```bash
python ping_pong.py
```

💡 Все графические и звуковые файлы должны находиться в корневой папке рядом с ping_pong.py.
